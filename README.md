# ALU AirBnB Clone

This project is a simplified clone of the AirBnB platform developed as part of the ALU Software Engineering curriculum. It consists of a command-line interface to create, read, update, and delete objects stored in a file.

---

## 🔧 Command Interpreter

The command interpreter (`console.py`) allows you to manage the AirBnB clone objects such as users, places, cities, and more.

It supports the following commands:
- `create <class>`: Creates a new instance of a class.
- `show <class> <id>`: Displays the string representation of an instance.
- `destroy <class> <id>`: Deletes an instance.
- `all [class]`: Shows all instances or all instances of a specific class.
- `update <class> <id> <attribute> <value>`: Updates an instance.
